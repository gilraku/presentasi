# Kenney Furniture Kit

Ready-made geometry by Kenney, Furniture Kit 2.0, CC0.

- Official source: https://kenney.nl/assets/furniture-kit
- License: https://creativecommons.org/publicdomain/zero/1.0/
- Download mirror: https://github.com/ETdoFresh/kenney.nl/tree/master/furniturekit_updated/Models/OBJ%20format
- Imported models: books, computerScreen, computerKeyboard.
- Original OBJ/MTL and license are retained here. `models.js` embeds their unchanged text for offline use, including when index.html is opened directly.
- Presentation adaptations: centering/scaling, common ink/ivory/gold materials, lighting and camera composition. No original model geometry was authored by AI.
- The report/form panels are simple UI geometry authored for the presentation.

OBJLoader and MTLLoader are unmodified Three.js r128 utilities, covered by vendor/THREE-LICENSE.txt.
